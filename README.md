# BMU Wallhausen – Website-Entwurf

Responsive Multipage-Website für **BMU Baumaschinen-Union Hohenlohe-Franken GmbH**, erstellt als Designvorschau von Kaiser Webdesign.

## Seiten

- `index.html` – Startseite
- `maschinen.html` – Maschinen & Marken
- `service.html` – Werkstatt & Service
- `unternehmen.html` – Unternehmen
- `kontakt.html` – Kontakt

## Technisches

Reines HTML, CSS und JavaScript, ohne Build-Schritt. Für eine lokale Vorschau `index.html` im Browser öffnen.

**Vor dem Livegang:** Maschinenfotos sind illustrative externe Quellen und ihre Nutzungsrechte müssen geprüft werden. Das Kontaktformular ist derzeit eine Demo mit E-Mail-Vorschau, kein serverseitiger Versand. Impressum und Datenschutz sowie die finalen BMU-Stammdaten ergänzen.
